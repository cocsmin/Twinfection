# 🧟‍♂️ Twinfection

**Twinfection** is an action-packed, top-down 2D survival shooter built with Phaser 3. Survive the undead horde alone or team up with a friend in local Co-Op. But beware: if a player falls to the horde...the rules change!

## 🎮 Features
* **Singleplayer & Local Co-Op:** Play alone or share the keyboard with a friend.
* **Infection Mechanic:** When a player dies in Co-Op, they mutate into a super-zombie, triggering an intense 1v1 PVP Showdown.
* **Dynamic Gameplay:** Procedurally generated cover/barricades, random loot drops (Health & Speed Boosts), and varied enemy types.
* **Arsenal:** Start with a Pistol and defeat Bosses to unlock the Magnum or the Machinegun.
* **Scaling Difficulty:** Endless waves with increasing enemy speed, health, and spawn rates.

## 🕹️ Controls

| Action | Player 1 (Red) | Player 2 (Blue) |
| :--- | :--- | :--- |
| **Move** | `W` `A` `S` `D` | `Arrow Keys` |
| **Attack** | `F` | `SPACE` |
| **Melee** | `E` | `ENTER` |

*Global Controls:*
* `P` - Pause/Resume Game
* `R` - Restart (Game Over Screen)
* `M` - Main Menu (Game Over Screen)

## 🛠️ Built With
* [Phaser 3](https://phaser.io/) - HTML5 Game Framework
* JavaScript (ES6 Modules)

## 🚀 How to Run Locally
1. Clone this repository: `git clone https://github.com/cocsmin/twinfection.git`
2. Open the project folder in your preferred IDE (e.g., VS Code).
3. Start a local web server (e.g., using the "Live Server" extension in VS Code).
4. Open `index.html` in your browser.
